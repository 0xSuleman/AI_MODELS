EXP 1 MQAR Associative Recall — Capacity Sweep

▼

Purpose & Hypothesis

This is the primary diagnostic experiment. The MQAR (Multi-Query Associative Recall) task forces the model to memorize N completely random key→value pairs and retrieve a specific value when queried. Because the data is random, statistical shortcuts are impossible — the model must store and retrieve from its d×d global memory matrix.

Core Hypothesis: The hybrid model's memory capacity scales with h × d² (number of heads × head dimension squared). As we increase num_pairs beyond d², accuracy should degrade — but increasing h should restore it. This directly validates the architectural claim.
What This Proves: If the model achieves high recall accuracy at pair counts approaching d², it mathematically proves that the salience-gated global memory is functioning as a genuine associative memory — not just a smoothed average. This is the single most important result for the paper.

EXP 2 Full Ablation Matrix on Associative Recall

▼

Purpose & Hypothesis

This experiment isolates the contribution of each architectural component. The full model must beat every ablation — otherwise the component being ablated is not contributing. We also compare against external baselines (softmax, linear, RALA).

Core Hypothesis: Full Hybrid > every ablation variant > vanilla linear attention. Softmax should be a strong baseline at low pair counts but the hybrid should match or beat it everywhere while being more efficient.
Critical Test: If "no salience gate" or "no φ gate" performs equally well, that component is not contributing and should be removed from the architecture or the claim must be weakened.

EXP 3 Scaling Curve — Time & Memory vs Sequence Length

▼

Purpose & Hypothesis

Measure wall-clock inference time and peak memory as sequence length N grows. This validates the O(Nd²) linear complexity claim against O(N²d) softmax.

Expected: Softmax time grows quadratically (2× tokens → 4× time). Hybrid grows linearly (2× tokens → 2× time). The curves should visibly diverge after N ≈ 256.
Method: Forward pass only (no training). Use torch.no_grad(). Warmup 3 passes, then time 10 passes and average. Report in milliseconds.

EXP 4 Recurrent vs Parallel Mode Validation

▼

Purpose & Hypothesis

The architecture claims dual-mode operation: parallel (training) and recurrent (streaming inference). We must prove recurrent mode does not degrade accuracy significantly compared to parallel mode on the same trained weights.

Method: Train in parallel mode, then evaluate the same checkpoint in both parallel and recurrent mode. Compare accuracy and output rank.
Acceptable degradation: Recurrent accuracy within 5% of parallel is acceptable. Beyond 10% is a problem that needs investigation.

EXP 7 Rank Diagnostics Deep Dive

▼

Purpose

Deep dive into the rank metrics to prove the φ gate's rank-restoration property. Compare per-layer memory rank ratio, global output rank ratio, and final output rank ratio across configurations.

Key prediction: Memory rank ratio < 1.0 (global memory bottleneck). Global output rank ≤ memory rank. But final output rank ≈ 1.0 (φ gate restores it). Without φ gate, output rank ≈ global output rank (no restoration).
